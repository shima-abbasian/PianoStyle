# Piano Style React Frontend

فرانت مستقل فروشگاه Piano Style با React، Vite و Tailwind CSS v4.

## اجرا

```powershell
cd D:\frontend-static
npm install
npm run dev
```

سپس `http://127.0.0.1:4173` را باز کنید.

## Build

```powershell
npm run build
npm run preview
```
